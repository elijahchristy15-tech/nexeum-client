# Nexeum Client

Star-themed PvP client for Fabric 1.21.

## Features

- Right Shift opens the in-game Nexeum settings screen
- Client-side PvP helpers: auto sprint, target HUD, cooldown meter, armor HUD
- Star-themed visuals: custom crosshair, nebula overlay, orbiting halo, comet trail
- Designed to stay compatible with other client-side Fabric mods
